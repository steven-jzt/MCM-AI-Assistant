# 数据预处理检查清单

> 建模手在推荐模型之前、编程手在实现算法之前，均需完成以下检查。

## 一、数据全貌
- [ ] 每个变量的统计摘要（均值、标准差、分位数、最小值、最大值）
- [ ] 每个关键变量的分布图（直方图或密度图）
- [ ] 变量间的散点图矩阵或相关系数矩阵

## 二、缺失值
- [ ] 统计每个变量的缺失比例
- [ ] 判断缺失模式（完全随机缺失 MCAR / 随机缺失 MAR / 非随机缺失 MNAR）
- [ ] 明确填补策略（删除 / 均值中位数填补 / 插值 / 模型预测）并记录理由

## 三、异常值
- [ ] 用统计方法检测异常值（箱线图 / Z-score / IQR）
- [ ] 区分"错误数据"和"极端但真实的数据"
- [ ] 明确处理策略（保留 / 剔除 / 修正）并记录理由

## 四、数据结构性
- [ ] 检查是否存在结构断点（数据生成机制在某点前后发生变化）
- [ ] 检查不同维度（时间/空间/组别）是否存在不一致（口径、单位、采样频率）
- [ ] 如存在断点或不一致，决定分段处理或给出全段适用证明

## 五、变量关系
- [ ] 检查自变量与因变量的关系形态（线性 / 非线性 / 无明显关系）
- [ ] 检查多重共线性（VIF 或相关系数矩阵）
- [ ] 判断是否需要变量变换（对数、标准化、归一化）
