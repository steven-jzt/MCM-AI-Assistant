## 常见陷阱

| 陷阱 | 对策 |
|------|------|
| 训练集信息泄漏到测试集 | 先切分，再分别做标准化/填充缺失值 |
| 随机种子未固定导致不可复现 | 所有涉及随机数的位置统一用 SEED=42 |
| 图表中文显示为方框 | 使用 `utils/visual.py`（已自动处理中文字体） |
| Excel 读取时中文乱码 | 用 `utils/data_loader.auto_load()` |
| 路径写死导致换机器后报错 | 使用相对路径，基于项目根目录构建 |
| 数值计算不稳定（如矩阵求逆） | 加正则项或改用伪逆 `np.linalg.pinv` |
| 全量数据直接喂算法被异常区污染 | 先做数据探索（见 `references/数据预处理检查清单.md`），筛选有效数据段 |
| 仅报告点估计缺误差范围 | 根据题目类型评估结果可信度：测量类合成不确定度，预测类做交叉验证 |
| 验证维度单一 | 组合多种验证方式（方法对照、数据分段、参数敏感性） |

## 不确定度合成模板（适用于测量/反演类题目）

```python
def synthesize_uncertainty(u_reg, u_method, u_param):
    """
    u_reg: 回归/拟合的随机不确定度
    u_method: 方法敏感性不确定度（如数据区间边界扫描的波动范围/2）
    u_param: 参数不确定度（如模型参数的文献偏差估计）
    
    返回合成不确定度 u_c。
    """
    u_c = np.sqrt(u_reg**2 + u_method**2 + u_param**2)
    print(f"不确定度分解:")
    print(f"  回归随机项:     {u_reg:.4f}")
    print(f"  方法敏感项:     {u_method:.4f}")
    print(f"  参数不确定项:   {u_param:.4f}")
    print(f"  合成不确定度:   {u_c:.4f}")
    return u_c
```
