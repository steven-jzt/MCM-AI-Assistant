# 图表选择与避坑指南

## 图表选择四问

1. **数据是什么类型？** 连续 vs 离散 / 单变量 vs 多变量 / 时间序列 vs 截面
2. **要传达什么信息？** 比较 vs 分布 vs 关系 vs 构成 vs 趋势
3. **受众是谁？** 评委需要在 30 秒内看懂你想说什么
4. **有几种替代方案？** 至少考虑 2 种图表类型再选择

## 数学建模场景速查表

| 信息类型 | 推荐图表 | 替代 |
|---------|---------|------|
| 指标排名 | 水平柱状图（降序排列） | 点+误差线 |
| 时间趋势 | 折线图 + 置信区间填充 | 多折线图（≤5 条线） |
| 预测 vs 实际 | 双折线 + 误差带 | 散点+45°参考线 |
| 多方案对比 | 分组柱状图 | 雷达图（≤6 维） |
| 相关性矩阵 | 热力图（RdBu_r / viridis） | 散点矩阵 |
| 聚类结果 | 散点图（前两个主成分着色） | 降维后散点 + 凸包 |
| 优化收敛 | 迭代-目标函数折线 | log-log 收敛图 |
| 灵敏度分析 | 龙卷风图 / 水平柱状图 | 多折线图（参数扫描） |
| 残差诊断 | QQ图 + 残差-拟合值散点 | 残差直方图 |
| 权重/贡献度 | 水平柱状图（降序） | 饼图（仅 ≤4 类） |

## 活跃避坑清单

以下问题在数学建模中高频出现，必须阻止：

| 问题 | 正确做法 |
|------|---------|
| 小样本（n<10）只用均值柱状图 | 散点图 + 均值横线，展示每个数据点 |
| 双 Y 轴图未标注左右轴含义 | 明确用颜色区分并标注，或拆为两张图 |
| 离散无序类别用折线连接 | 改用柱状图（类别无序时折线暗示趋势） |
| 稀疏率折线图呈锯齿状 | 增加平滑或改用柱状图 |
| 使用饼图 / 3D 图表 | 饼图仅用于 ≤4 类别的占比；禁用 3D |
| 轴截断（不从 0 开始但对比较敏感时） | 柱状图必须从 0 开始；折线图可从数据范围开始 |
| 仅有少数估计值却使用巨大柱状图 | 缩小图宽，或在柱顶加数值标注 |
| 2×2 热力图仍使用 colorbar | 2×2 矩阵直接标注数值，无需 colorbar |
| 仅用红/绿区分 | 加入蓝色通道或改用色盲调色板 |
| 标题过长 / 图例过大 | 标题 ≤15 字；图例 frameon=False，字号 7pt |
| 数据点标记过于密集 | 散点降低 alpha 或缩小点；折线去掉 marker |
| 重要性柱状图纹理过于密集 | 纯色填充 + 细白边，不要交叉线/斜线填充 |
| 未标注误差线/显著性 | 需要展示不确定性时必须标注 |
| 图表元素被裁切（clipping） | 关闭 bbox_inches='tight' 后检查边界 |
| 使用 JPEG 格式保存图表 | 必须 PNG（≥300 DPI）+ SVG 双格式 |
