# 编程手质检清单（P1/P2 自检）

## P1 门自检 — 候选模型竞争淘汰
- [ ] `check_env.py` 运行通过，所需依赖齐全
- [ ] 数据加载成功（`auto_load()` 无报错）
- [ ] 同一 mini-batch 数据集上运行了全部候选模型（2-3 个）
- [ ] 已产出竞争对比表（核心指标 + 运行时间 + 数据假设满足度）
- [ ] 淘汰规则执行正确：复杂模型全指标不如简单基准已淘汰；指标接近（<10%）全部保留；物理意义错误已淘汰
- [ ] 输出结果与建模手的结论目标形式一致
- [ ] 无明显数值异常（数量级/符号）

## P2 门自检 — 交付前终检

### 代码
- [ ] `python code/main.py` 一键可跑，无需手动修改
- [ ] 随机种子固定为 42
- [ ] 关键参数在 `config.py` 或文件头部声明

### 图表
- [ ] ≥9 张图，覆盖 raw_ / process_ / result_ 三类
- [ ] 每张图有 PNG + SVG 双格式
- [ ] 无 JPEG 文件
- [ ] `figure_audit.py figures/` 通过（无 FAIL）
- [ ] 每类 ≥3 张，覆盖所有子问题
- [ ] 无饼图（>4 类时）/无 3D 图/无 jet colormap

### 表格
- [ ] 结果保存为 CSV（或 XLSX 若题目要求）
- [ ] 数值保留适当有效数字
- [ ] 表头清晰，含单位（如适用）

### 复现清单
- [ ] `results/复现清单.json` 已生成
- [ ] 包含 seed、输入文件 SHA-256、依赖版本、复现命令

### 一致性
- [ ] 代码输出数值与论文中引用的数值一致
- [ ] 变量名遵循"术语表格.md"的符号约定

## 返工规则
- P1 FAIL → 一阶返工：修可复现性，补足缺失依赖/数据加载/数据筛选理由。二阶回退：所有候选模型均不满足要求或出现物理意义错误 → 退回建模手重建候选池
- P2 FAIL → 修代码/图/表/清单中的具体问题，按回执指引返工
