# 可视化规范

## 三类图表体系

| 类别 | 前缀 | 内容 | 最少数量 |
|------|------|------|---------|
| 原始数据图 | `raw_` | 数据分布、缺失值概览、相关性矩阵 | ≥3 |
| 处理过程图 | `process_` | 模型拟合对比、收敛曲线、残差诊断 | ≥3 |
| 最终结果图 | `result_` | 预测结果、最优方案、灵敏度分析 | ≥3 |

总计 ≥9 张，覆盖全部子问题。

## 出版级样式基准

- 白底，无右侧和顶部坐标轴脊线（`ax.spines["top"].set_visible(False)` 等）
- 无网格（或仅在需要精确读数时使用极淡网格 `alpha=0.1`）
- 标签字体 7-9pt，标题 9-10pt
- 最小字号不低于 6pt（印刷后仍可辨识）
- 色盲友好调色板（viridis/magma/cividis 或 Wang/Tol 离散调色板）
- 禁用彩虹色阶（jet/rainbow）
- 禁用红-绿唯一颜色对（色盲无法分辨）

## 图表制作流程（Nature/SCI 可视化论证法）

1. **一句话结论**：每张图先用一句话写清楚"这张图说明了什么"
2. **叙事原型**：在纸上勾勒图表的大致布局（panel 数量、坐标轴关系）
3. **视觉层次**：确定主数据层（最深色/最粗线）→ 辅助层 → 参考层（基线、标注）
4. **视觉编码**：颜色映射连续变量用 `viridis`（感知均匀），分类变量用 Wang/Tol 离散调色板
5. **终稿尺寸**：单栏 3.5 英寸宽，双栏 7.2 英寸宽，报告全宽 6.3 英寸
6. **三层检查**：
   - 布局审查（glyph/layout/clipping/tick overlap）
   - 设计审查（标题长度、图例数量、标记密度、基线、colorbar 合理性）
   - 灰阶审查（转为灰度后关键信息是否仍可辨）

## 导出自检循环

1. 生成 PNG（≥300 DPI）+ SVG 双格式
2. 运行 `figure_audit.py figures/` 审计
3. 生成灰阶预览至 `figures/_qa/` 目录
4. 如果灰阶下关键对比丢失 → 调整颜色或增加线型/标记区分

## 导出配置（Python）

```python
import matplotlib.pyplot as plt

# 出版级参数
plt.rcParams.update({
    "font.size": 7.5,
    "axes.spines.top": False,
    "axes.spines.right": False,
    "axes.grid": False,
    "svg.fonttype": "none",       # SVG 文字导出为路径
    "pdf.fonttype": 42,
    "savefig.dpi": 300,
    "figure.facecolor": "white",
    "axes.facecolor": "white",
})
```

或直接调用 `utils/visual.py` 中的 `apply_publication_style()`。

## 图表合同（Figure Contract）

每张图在绘制前填写以下 14 字段：

| 字段 | 示例 |
|------|------|
| 文件名 | `result_q1_supplier_ranking.png` |
| 一句话结论 | 供应商 A 综合得分最高（0.87），远超第二名 B（0.62） |
| 图表类型 | 分组柱状图 |
| X 轴 | 供应商名称 |
| Y 轴 | 综合得分（0-1） |
| 分组变量 | 评价维度（质量/价格/交付） |
| 颜色映射 | Wang 调色板，每组一色 |
| Panel 数 | 1 |
| 图宽（英寸） | 6.3 |
| 目标 DPI | 300 |
| 图例位置 | 右上，frameon=False |
| 标注 | 柱顶标注数值 |
| 参考线 | y=0.5 虚线标注中等水平 |
| 特殊处理 | 无 |

## 禁止使用的图表类型

- **饼图**（类别 >4 时）：改用分组柱状图
- **3D 图表**：在二维平面上造成透视失真
- **双 Y 轴图**（除非量纲完全不同且明确标注）：容易误导
- **离散类别用折线连接**：类别无序时用柱状图
- **小样本（n<10）的均值柱状图**：改用散点+均值线
- **截图/JPEG**：必须用 PNG/SVG
