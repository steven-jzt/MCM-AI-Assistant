# 建模手常见模式

## 11 种经典模型搭配

### 1. 线性/整数规划 + 灵敏度分析
适用：资源分配、生产调度、物流选址等有明确目标函数和约束的优化问题。
关键点：必须做灵敏度分析，展示参数变化对最优解的影响。

### 2. 启发式算法 + 对比实验
适用：NP-hard 问题（大规模 TSP、VRP、排产等），精确算法不可行。
关键点：与精确解（小规模）或已知基准对比；记录收敛曲线。

### 3. 多目标优化 + Pareto 前沿
适用：多个冲突目标（成本 vs 质量 vs 时间）。
关键点：展示 Pareto 前沿，给出折中方案的选取依据。

### 4. 单模型预测 + 误差检验
适用：数据量适中（30-200 点），单一趋势明显的序列。
关键点：必须输出训练/测试误差对比和过拟合风险评估。

### 5. 双模型/集成预测
适用：数据量大或规律复杂，单模型可能不稳定。
关键点：加权平均或 stacking，对比单模型 vs 集成的误差。

### 6. 组合预测
适用：多种预测方法各有优劣，需要取长补短。
关键点：权重确定方式（最小二乘/熵权/等权），对比各单项。

### 7. 加权 + 综合评价
适用：多指标排名、方案优选、绩效评价。
经典组合：熵权法 + TOPSIS，AHP + 模糊综合评价。

### 8. DEA（数据包络分析）
适用：多投入多产出效率评价（如企业效率、学校绩效）。
关键点：区分技术效率和规模效率。

### 9. 优化 + 仿真
适用：含不确定性的优化问题（随机需求、随机到达）。
关键点：蒙特卡洛仿真 + 优化迭代，记录多次运行的统计分布。

### 10. 评价 + 优化
适用：先排序/评价筛选，再对优选对象进行优化配置。
关键点：两阶段衔接的逻辑必须自洽。

### 11. 预测 + 决策
适用：基于预测结果做多情景决策分析。
关键点：预测的不确定性要传递到决策环节。

### 12. 变量变换 + 线性回归
适用：因变量与自变量之间存在非线性函数关系，但可通过变量变换转为线性。
关键点：
- 识别非线性来源，构造新变量将非线性吸收进坐标中
- 常见变换：取对数（指数/幂律关系）、取倒数、构造组合变量
- 变换后使用一元或多元线性回归，R² 直观可检验
- 优势：不依赖初值、不存在局部最优、参数意义明确

### 13. 变换域分析（含数据质量前置）
适用：通过 FFT/小波变换等提取信号的频率或周期特征。
**前置检查**：
- 信号是否包含生成机制不同的区段？（如有，先分段或筛选）
- 信号是否平稳？是否存在趋势或结构性断点？
- 变换域主峰特征是否在合理范围内？
关键点：变换域方法提供粗估，建议用另一种独立方法交叉验证。

## 模型搭配决策树

```
问题类型？
├── 评价/排名 → 熵权+TOPSIS / AHP+模糊评价 / DEA
├── 预测
│   ├── 数据 < 30 点 → GM(1,1) / 指数平滑
│   ├── 数据 30-500 点 → ARIMA / Prophet
│   └── 数据 > 500 点 → LSTM / XGBoost
├── 优化
│   ├── 线性/连续 → 线性规划
│   ├── 整数/组合 → 整数规划 / 遗传算法
│   └── 多目标 → NSGA-II / 加权变为单目标
├── 分类/聚类 → K-means / 层次聚类 / 随机森林
└── 机理建模 → 微分方程 / 元胞自动机 / 排队论
```
