# Word 论文格式规范

> 论文内容结构与格式必须遵循目标竞赛当届官方规则与官方模板。本文件给出 Word（DOCX）生成流程与校验要点；详细格式参数（页边距、字体、字号、摘要、页数上限、匿名要求、参考文献、AI 使用说明）见 `references/论文规范摘要.md`。

## 唯一权威来源

- 全国大学生数学建模竞赛（CUMCM）：`http://www.mcm.edu.cn/`
- MCM/ICM（COMAP）：`https://www.comap.com/contests/mcm-icm`
- 校赛/华数杯：以当届官方通知为准

竞赛规则可能更新。生成前必须确认届次与官方文件版本，不能把仓库默认值当作永久规则。

## 生成流程（python-docx）

使用 `tools/docx/scripts/paper_format.py`（完整入口见 `tools/docx/SKILL.md`）：

```python
from tools.docx.scripts.paper_format import (
    new_document, setup_page, title, heading1, heading2,
    body, three_line_table, equation, save_document, validate_paper_structure,
)

doc = new_document()
setup_page(doc, contest="cumcm")      # 页边距/纸张（其他竞赛按官方模板调整）
title(doc, "论文题目")
heading1(doc, "一、问题重述")
body(doc, "正文内容……")
three_line_table(doc, headers=["指标", "值", "单位"], rows=[["GDP", "120.5", "亿元"]])
equation(doc, "E = mc^2")             # 公式，见下方「公式」
issues = validate_paper_structure(doc, contest="cumcm")
save_document(doc, "完整论文.docx")
```

## 公式

- `equation()` 与 `tools/docx/scripts/equations.py` 把 LaTeX 公式转成可编辑的公式文本：`latex_to_unicode()`（LaTeX→Unicode）与 `replace_placeholders()`（DOCX 占位符批量替换）。
- 复杂公式优先用 Pandoc 的 LaTeX→OMML 转换后做 DOCX 校验；最终公式必须可编辑，不能是截图或纯文本 LaTeX。

## 表格与图

- 表格必须可编辑；三线表使用 `three_line_table()`。
- 图来自编程手真实运行结果，可从候选图中选择。
- 每幅图和每个表必须有连续编号与题注，并在正文中至少引用一次；单位和数值必须一致。

## 校验

- 结构校验：`validate_paper_structure(doc, contest="cumcm")`，报告篇幅、公式/图/表数量、图表编号与正文引用、参考文献对应等问题。
- 详细格式与提交要求（摘要 ≤1 页、正文 ≤30 页、无页眉、匿名、附录源码、AI 使用说明）见 `references/论文规范摘要.md`。
