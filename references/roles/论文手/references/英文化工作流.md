# MCM/ICM 英文写作工作流

## 适用场景
- MCM（Mathematical Contest in Modeling）
- ICM（Interdisciplinary Contest in Modeling）
- 其他需要英文论文的国际数学建模竞赛

## 三阶段流程

```
理解中文稿 → 撰写英文稿 → 校准润色
```

---

## 一、英文摘要模板

### 标准结构（Context → Gap → Approach → Result → Boundary → Implication）

```
[Context] With the increasing complexity of [problem domain], 
[core problem] has become a critical challenge in [field].

[Gap] Existing approaches often fall short in [specific limitation],
necessitating a more [desired property] methodology.

[Approach] In this paper, we establish a [model type] that incorporates
[key innovation]. For Problem 1, [method 1] is employed to [purpose 1].
For Problem 2, [method 2] is developed to [purpose 2].
For Problem 3, [method 3] is applied to [purpose 3].

[Result] Numerical results demonstrate that [key finding 1],
with [quantitative evidence]. Compared to [baseline],
our model achieves [improvement metric].

[Boundary] The proposed model assumes [key assumption] and
may be less applicable when [limiting condition].

[Implication] This work provides [practical insight] for
[application domain] and suggests [future direction].

Keywords: [keyword 1], [keyword 2], [keyword 3], [keyword 4], [keyword 5]
```

### 核心原则
- 第一句交代背景和问题
- 中间段落说明方法（动词用一般现在时）
- 结果用具体数值
- 不超过 1 页
- 避免 "we think" / "we believe" → 用 "results indicate" / "findings suggest"

## 二、常见中式英文修正表

| 中式表达 | 问题 | 修正 |
|---------|------|------|
| "We use A method to solve the problem" | 过于口语化 | "Problem X is addressed using A" |
| "The result is very good" | very 空洞 | "The result achieves a 12% improvement" |
| "By this way, we can..." | 非惯用表达 | "In this manner" / "Through this approach" |
| "Compared with other methods, ours is better" | 不具体 | "Our model outperforms the ARIMA baseline by 8.3% in RMSE" |
| "We all know that..." | 学术写作禁用 | 直接陈述事实或引用文献 |
| "It is obvious that..." | 不严谨 | "As shown in Table 2" / "Equation (5) indicates" |
| "The data is..." (data 是复数) | 语法 | "The data are..." 或 "The dataset is..." |
| "It can be seen from Fig.1" | 啰嗦 | "Figure 1 shows..." |
| "plays an important role" | 模糊 | "is essential for..." / "directly affects..." |
| "more and more" | 口语化 | "increasingly" / "growing" |

---

## 三、动词力度层级

| 力度 | 示例动词 | 适用场景 |
|------|---------|---------|
| 强（因果） | demonstrate, establish, confirm, validate | 有充分证据支撑的结论 |
| 中（关联） | indicate, suggest, reveal, highlight | 统计关联，非严格因果 |
| 弱（可能） | imply, appear to, tend to, may contribute to | 推测性或受限于数据 |

**原则**：不要把所有结论都写成 "prove" / "demonstrate"。统计模型的结果用 "indicate" / "suggest" 更严谨。

## 四、学术短语库

### 引出问题
- "The central challenge in [field] is to..."
- "An open question in [domain] concerns..."
- "[Problem] has received considerable attention in recent years."

### 介绍方法
- "We formulate the problem as..."
- "The model builds upon [prior work] while extending it to..."
- "To address this, we introduce a [type] framework that..."

### 引出结果
- "Numerical experiments on [dataset] reveal that..."
- "As summarized in Table X, the proposed approach yields..."
- "Several patterns emerge from the analysis:"

### 对比分析
- "Our model achieves a [X%] improvement over [baseline]."
- "The performance gap is most pronounced when [condition]."
- "While [method A] excels in [aspect X], [method B] proves superior in [aspect Y]."

### 讨论局限性
- "It should be noted that our analysis assumes..."
- "A limitation of this study is..."
- "The generalizability of these results is subject to..."

### 结论
- "Taken together, these findings suggest..."
- "This work contributes to [field] by..."
- "Future work could extend this approach to..."

## 五、段落检查清单

写完每个段落后检查：

- [ ] 每段只有一个中心意思（首句概括）
- [ ] 段落长度 ≤ 150 词（过长则拆分）
- [ ] 连接词合理（However/Therefore/Furthermore/In contrast/Specifically）
- [ ] 无中式英文（对照修正表）
- [ ] 所有缩写首次出现时已全称标注（如 "Analytic Hierarchy Process (AHP)"）
- [ ] 数字/百分数格式正确（"12.3%" 而非 "12.3 percent"）
- [ ] 公式在句中时标点正确（公式末尾的逗号/句号）

## 六、格式差异（MCM/ICM vs CUMCM）

| 项目 | CUMCM | MCM/ICM |
|------|-------|---------|
| 论文语言 | 中文 | 英文 |
| 页面大小 | A4 | US Letter |
| 正文页数上限 | 30 页 | 25 页（MCM）/ 25 页（ICM） |
| 摘要 | 中文，≤1 页 | 英文，≤1 页 |
| 标题格式 | "一、问题重述" | "1. Problem Restatement" |
| 字体 | 宋体 + 黑体 | Times New Roman (12pt) |
| 页边距 | 上下 2.54cm, 左右 3.18cm | 1 inch 四周 |
