## 一、论文A（A212）—— 回焊炉温曲线优化控制

### 1.1 论文结构

| 章节 | 内容要点 | 篇幅（估计） |
|------|---------|-------------|
| 摘要 | 问题概述 + 每问方法 + 最终结论 | ~1/2页 |
| 问题重述 | 背景（SMT生产）+ 四个子问题要求 | ~1页 |
| 问题分析 | 物理机理分析 + 各问题递进关系 | ~1页 |
| 模型假设 | 一维传热、常物性参数等假设 | ~1/2页 |
| 符号说明 | 温度、热传导系数、炉温等 | ~1/2页 |
| **模型一**：炉温曲线机理模型 | 一维热传导方程 + 牛顿冷却定律 + 有限差分数值解 | ~3-4页 |
| **模型二**：最大传送带速度 | 单目标优化 + 制程界限约束 | ~2页 |
| **模型三**：最小化>217℃面积 | 决策变量（各温区温度、速度）+ 遗传算法/PSO | ~2-3页 |
| **模型四**：对称性多目标优化 | 双目标→线性加权归一化 + 偏态系数 | ~2页 |
| 模型评价与推广 | 优点/缺点/推广方向 | ~1/2页 |
| 参考文献 + 附录 | 代码、详细数据表格 | 篇幅较大 |

**结构特色**：
- 四个子问题按照"机理建模→单目标优化→多目标优化"的逻辑链递进
- 每个子问题前有"建模思路"小节做铺垫，适合评委快速理解
- 问题的递进关系非常清晰：机理方程一旦建立，后续优化问题都在同一物理框架下进行

### 1.2 模型选择

| 子问题 | 模型 | 理由 |
|--------|------|------|
| 温度曲线建模 | 一维热传导方程（傅里叶导热定律）+ 牛顿冷却定律（对流边界） | 题目核心物理机理 |
| 间隙温度处理 | 相邻温区线性插值 | 工程近似，简单可靠 |
| 数值求解 | 有限差分法（前向/后向欧拉、Crank-Nicolson） | PDE的标准数值解法 |
| 参数估计（比热容 $k$） | 最小二乘法拟合实验数据 | 反问题，数据驱动 |
| 最大速度优化 | 二分法搜索 / 遍历 65~100 cm/min | 单变量，穷举可靠 |
| 面积最小化 | 遗传算法（GA）/ 粒子群算法（PSO） | 多变量非线性全局优化 |
| 对称性+面积 | 线性加权归一化为单目标 | 多目标处理的经典方法 |
| 对称性指标 | 偏态系数 / >217℃两侧温差平方和 | 创新点，量化"对称性" |

**模型串联逻辑**：
```
热传导方程(机理) → 有限差分(求解) → 参数拟合(标定)
    ↓
单目标优化(速度最大化) → 利用已标定的机理模型作为约束
    ↓
多变量优化(温度+速度) → 遗传算法/PSO
    ↓
多目标优化(面积+对称性) → 加权归一化
```

**创新/亮点**：
- 将复杂的PID控温问题简化为可求解的一维传热模型，抓住了问题本质
- 对称性指标（偏态系数）的构造具有原创性
- 参数拟合（最小二乘法反推比热容）体现了机理与数据的结合

### 1.3 图表技巧

根据典型优秀论文特征推断：
- **炉温曲线图**：展示温度-时间/位置关系，标注关键温度点（150℃、190℃、217℃、峰值）
- **制程界限示意图**：在一条炉温曲线上标注各约束区间
- **优化收敛曲线**：遗传算法/PSO的迭代收敛图（证明算法有效性）
- **对比图**：优化前后炉温曲线对比
- **表格**：各温区设定温度、传送带速度、关键温度点结果、约束满足情况

**图表最佳实践**：
- 炉温曲线图上直接标注 >217℃的时间区间和峰值温度
- 使用不同颜色区分预热区、恒温区、回流区、冷却区
- 表格使用三线表格式

### 1.4 写作句式

**摘要模式**：
> "本文针对回焊炉温曲线优化控制问题，建立了基于一维热传导方程的机理模型..."

**模型假设表述**：
> "假设焊接区域的传热可简化为一维问题，忽略横向热传导"
> "假设电路板的热物理参数（密度、比热容、导热系数）为常数"

**结论/推广**：
> "本文建立的模型可为实际SMT生产工艺的参数设定提供理论参考"

### 1.5 评委喜欢的点

1. **机理与数据结合**：不是纯统计也不是纯理论，热传导方程 + 参数拟合体现了建模的完整性
2. **约束处理细致**：制程界限的五个约束（升温斜率、150-190℃持续时间、>217℃时间、峰值温度范围等）逐一处理
3. **算法对比**：如果比较了不同优化算法（如GA vs PSO）的效果，会是加分项
4. **灵敏度分析**：对关键参数（如比热容 $k$）做灵敏度分析，验证模型鲁棒性
5. **误差分析**：模型预测值与实验数据对比，计算相对误差
6. **代码附录**：有限差分+优化算法的完整代码

### 1.6 可复用模板片段

1. **机理建模引入句**：
   > "根据[物理定律/领域原理]，...过程可由...方程描述：$$...[公式]...$$ 其中，$x$ 表示...，$t$ 表示...，边界条件为...，初始条件为..."

2. **优化问题转化句**：
   > "将原问题转化为以...为决策变量，以...为目标函数，以...为约束条件的优化问题。"

3. **数值求解过渡句**：
   > "由于上述方程难以获得解析解，本文采用[方法名]进行数值求解，时间步长取...，空间步长取..."

4. **模型验证句**：
   > "将模型计算结果与实验数据对比，两者吻合良好，最大相对误差不超过...%，验证了模型的准确性。"

## 二、论文B（C305）—— 银行基于大数据挖掘对中小微企业的信贷决策问题

### 2.1 论文结构

| 章节 | 内容要点 | 篇幅 |
|------|---------|------|
| 摘要 | 三问方法概述 + 关键词 | ~3/4页（34行） |
| 一、问题重述 | 1.1 问题背景 + 1.2 问题的提出（三问分列） | ~1页 |
| 二、问题分析 | 2.1-2.3 逐问分析 + 整体思路图（图1） | ~2页 |
| 三、模型基本假设与合理性说明 | 5条假设，每条附合理性解释 | ~1/2页 |
| 四、符号说明 | 11个核心符号的三线表 | ~1/4页 |
| **五**、问题一模型 | 5.1 建模思路 → 5.2 建模准备（数据预处理+Logistic） → 5.3 多目标规划 → 5.4 计算步骤 → 5.5 计算结果 → 5.6 结果分析与检验（主成分验证） | ~7页 |
| **六**、问题二模型 | 6.1 思路 → 6.2 准备（欧氏距离判定信誉等级） → 6.3 多目标规划 → 6.4-6.6 | ~6页 |
| **七**、问题三模型 | 7.1 思路 → 7.2 准备（疫情行业分析+指标改进） → 7.3 多目标规划 → 7.4-7.6 | ~5页 |
| **八**、模型评价与推广 | 优点3条 + 缺点3条 + 推广2条 | ~1页 |
| 参考文献 | 5条，含期刊、百科、政府文件 | ~1/4页 |
| 九、附录 | 附录一~四：四问的完整数据表格，共15+页 | ~15页 |

**结构特色**：
- 三个子问题采用**相同的求解框架**（Logistic回归 → 多目标规划 → 结果检验），只是每个问题的输入不同，这种"框架统一、逐问嵌套"的结构让论文逻辑清晰，也降低了阅读难度
- **图1 整体建模思路流程图**放在问题分析结尾处，起到了"总领"作用
- 每个建模章节包含完整的"思路→准备→建模→计算→结果→检验"子结构
- 附录占了论文将近一半篇幅，数据非常完整，评委可轻松重现结果

### 2.2 模型选择

| 子问题 | 模型 | 理由与评价 |
|--------|------|-----------|
| 信贷风险量化 | Logistic回归（6个指标） | 简单直接，输出天然是[0,1]概率；但指标构造略显简单 |
| 问题二信誉判定 | 欧氏距离最近邻 | 创新但有简化过度之嫌（仅用净发票总金额一个变量做距离判断） |
| 三个问题的决策优化 | 多目标规划（max净收益 + min风险） | 框架统一，三问共享，便于递进 |
| 守约率→风险转化 | $1-p_i$ 映射 | 直观但有线性假设隐含 |
| 结果验证 | 主成分分析（PCA） | 用PCA综合得分与守约率做散点图验证 |
| 客户流失率 | 对数函数拟合 $y=2.2386+0.669\ln r$ | 基于附件3数据拟合，有数据支撑 |
| 突发因素处理 | 政策利率下浮10% + 行业差异乘数 | 第三问的创新点，但乘数确定略显主观 |

**模型串联逻辑**：
```
数据预处理(剔除作废发票+异常值+重复发票)
    ↓
Logistic回归(6个指标 → 企业守约率p_i)
    ↓
多目标规划(决策变量: 贷款金额x_i + 贷款利率r_i)
    ↓ → 问题二: 先欧氏距离判信用等级 → 再套Logistic → 再套多目标规划
    ↓ → 问题三: 先行业分类+疫情影响乘数 → 再改进指标 → 再套Logistic → 再套多目标规划
```

**创新/亮点**：
- 欧氏距离判定信誉等级是本文"独到之处"（作者自评）
- 三个问题嵌套同一框架的设计使得论文结构极其清晰
- 资金周转率、变异系数等指标的构造体现了对"企业实力"的深入理解

**不足**：
- Logistic回归仅用6个指标，特征工程深度有限
- 欧氏距离只用净发票总金额判定信用等级，信息利用不充分
- 疫情对不同行业的影响乘数确定方法不够严谨

### 2.4 写作句式

#### 摘要（非常典型的竞赛摘要结构）

> "本文主要研究了银行针对中小微企业的信贷决策问题。信贷决策需要银行利用各企业的相关资料与信息，在对企业进行综合评价之后做出是否放贷、放贷多少、期限多久和利率多少等决策的问题。"

分析：第一句点题，第二句细化问题内涵。

> "针对问题一，根据题目要求，我们首先要对企业的信贷风险进行量化分析，在量化分析时，我们将风险的量化问题转化为客户守约率问题，建立 Logistic 回归模型..."

分析：每个问题的描述遵循"要求 → 思路 → 方法（模型）→ 工具 → 结果"的顺序。

> "最后，本文对模型进行了优、缺点评价与模型推广，得出该模型还可以向银行面对的其他对象和生活的其它方面进行推广的结论。"

分析：结尾句概括了模型评价和推广价值，体现了研究的完整性。

#### 问题分析

> "该问题是常见的信贷决策大数据分析问题，要解决此类问题我们首先将风险的量化问题转化为客户守约率问题..."

> "综上所述：对于中小微企业的信贷决策问题的三个小问之间为层层深入的关系，我们在解决三个问题时的总体思路为将模型朝着问题一的模型的方向转换，即将二、三两问看作问题一的推广。"

> "所以解决问题一的关健为：指标的选取与构造；问题二的关键点在于用第一问的数据对问题二中的缺失数据进行预测与计算；问题三的关键点在于弄清疫情对不同行业、不同类别的企业产生的不同的影响。"

分析：问题分析末尾的总领性段落非常出色——既点明三问关系（层层深入），又指出每问的关键难点。

#### 模型假设（每条都有合理性说明）

> "假设 2：信用等级是离散的，且在同一等级中的企业违约的概率相同。在利用 Excel 表格对数据进行筛选之后，我们发现违约企业大多为信誉评级为C、D两个等级的企业，A、B两个等级的企业很少违约。"

分析：假设后面跟"合理性说明"，数据支撑假设——**这是优秀论文的标志**。

#### 模型评价

> "本文在建模之前都对数据进行了预处理，使得数据更加真实可靠。"
> "本文利用欧式距离来确定信誉等级，是本文模型的创新与独到之处。"
> "本文在解决问题时，套用的模型较为简单、易于理解，简化了问题的求解难度。"

分析：优点列举具体、有论据支撑，不是泛泛而谈。

> "本题的数据量较大，但解决本题时没有用专门的数据处理软件，到时操作繁琐，等待时间较长。"

分析：缺点也敢于承认，体现了学术诚实。

### 2.5 评委可能喜欢的点

1. **完整的附录**：附录一~四提供了三个问题的全部计算结果（123+302+302家企业），评委可以逐行核查

5. **客户流失率拟合**：利用附件3数据拟合出对数函数关系，有数据支撑
6. **层层嵌套的模型结构**：三问共享同一框架，逻辑自洽
7. **框架流程图**：图1 整体建模思路图帮助评委快速理解全文
8. **问题分析段落的总领句**：明确点出三问关系和各问关键点

## 三、横向对比

### 3.1 共性特征

| 维度 | 共性 |
|------|------|
