# 综合类算法说明

## 1. 蒙特卡洛模拟

### 算法介绍
通过大量随机采样来估计确定性问题的数值解或随机系统的统计特性。

### 适用范围
- 计算复杂积分/期望
- 随机系统仿真（排队、库存、风险）
- 模型参数的不确定性传播
- 结果稳定性的随机验证

### 代码实现要点
```python
import numpy as np

def monte_carlo_integration(f, bounds, n_samples=100000):
    """蒙特卡洛定积分"""
    dim = len(bounds)
    volume = np.prod([b[1] - b[0] for b in bounds])
    samples = np.random.uniform(
        low=[b[0] for b in bounds],
        high=[b[1] for b in bounds],
        size=(n_samples, dim)
    )
    f_values = np.apply_along_axis(lambda x: f(*x), 1, samples)
    estimate = volume * f_values.mean()
    se = volume * f_values.std() / np.sqrt(n_samples)
    return estimate, se  # 点估计和标准误
```

### 选择指南
- 计算积分/期望（高维时优于数值积分）→ 蒙特卡洛
- 需要概率分布而不仅是点估计 → 蒙特卡洛 + 统计输出
- 确定性系统的小参数扰动 → 优于蒙特卡洛（用灵敏度分析代替）

## 2. 排队论

### 算法介绍
用数学方法分析服务系统中顾客的到达、等待和服务过程。

### 标准模型
| 模型 | 到达过程 | 服务时间 | 服务台数 | 典型指标 |
|------|---------|---------|---------|---------|
| M/M/1 | Poisson | 指数 | 1 | 平均队长 $L = \lambda/(\mu-\lambda)$ |
| M/M/c | Poisson | 指数 | c | 等待概率 $P(W>0)$ |
| M/G/1 | Poisson | 一般分布 | 1 | Pollaczek-Khinchin 公式 |
| G/G/c | 一般分布 | 一般分布 | c | 需仿真求解 |

### 代码实现要点
```python
import numpy as np

def mm1_queue(arrival_rate, service_rate, max_time=1000):
    """M/M/1 排队系统仿真"""
    rho = arrival_rate / service_rate
    if rho >= 1:
        raise ValueError("系统不稳定：ρ ≥ 1")

    # 理论值
    L = rho / (1 - rho)           # 平均队长
    W = 1 / (service_rate - arrival_rate)  # 平均逗留时间
    Wq = rho / (service_rate - arrival_rate)  # 平均等待时间

    return {"rho": rho, "L": L, "W": W, "Wq": Wq}
```

### 选择指南
- 服务系统设计/优化（银行、医院、呼叫中心）→ 排队论
- 数据符合标准分布假设 → 解析模型（M/M/c 等公式）
- 数据分布复杂或需要细节仿真 → 离散事件仿真

## 3. 博弈论

### 算法介绍
研究多个决策主体在相互影响下的策略选择与均衡。

### 典型模型
- **完全信息静态博弈**：Nash 均衡（纯策略/混合策略）
- **完全信息动态博弈**：子博弈精炼 Nash 均衡、逆向归纳法
- **演化博弈**：复制者动态方程、演化稳定策略
- **合作博弈**：Shapley 值、核（core）

### 代码实现要点
```python
import numpy as np

def find_nash_equilibrium(payoff_matrix_a, payoff_matrix_b):
    """寻找两人博弈的纯策略 Nash 均衡"""
    a = np.array(payoff_matrix_a)
    b = np.array(payoff_matrix_b)
    equilibria = []
    for i in range(a.shape[0]):
        for j in range(a.shape[1]):
            row_best = a[i, j] >= a[:, j].max()
            col_best = b[i, j] >= b[i, :].max()
            if row_best and col_best:
                equilibria.append((i, j))
    return equilibria
```

### 选择指南
- 多方利益冲突的决策问题 → 博弈论
- 政策/制度设计 → 机制设计/合作博弈
- 群体行为演化 → 演化博弈 + 复制者动态

## 4. 元胞自动机

### 算法介绍
离散的时空动力系统，通过局部规则涌现全局模式。规则定义在网格上，每个元胞的状态根据邻域状态同步更新。

### 适用范围
- 交通流模拟
- 人群疏散仿真
- 传染病传播
- 土地利用变化
- 森林火灾蔓延

### 代码实现要点
```python
import numpy as np

def cellular_automaton_step(grid, rule_func):
    """元胞自动机单步迭代"""
    rows, cols = grid.shape
    new_grid = grid.copy()
    for i in range(1, rows - 1):
        for j in range(1, cols - 1):
            neighborhood = grid[i-1:i+2, j-1:j+2]
            new_grid[i, j] = rule_func(neighborhood)
    return new_grid

# 经典 Conway 生命游戏规则
def conway_rule(neighborhood):
    center = neighborhood[1, 1]
    alive_neighbors = neighborhood.sum() - center
    if center == 1:
        return 1 if 2 <= alive_neighbors <= 3 else 0
    else:
        return 1 if alive_neighbors == 3 else 0
```

### 选择指南
- 离散空间+局部交互+时间演化 → 元胞自动机
- 连续空间/宏观尺度 → 微分方程（PDE）
- 个体异质性强 → Agent-Based Model

## 5. 马尔可夫链

### 算法介绍
状态转移只依赖于当前状态的随机过程（无记忆性）。

### 典型应用
- 天气预报的状态转移
- 用户行为序列建模
- 排队系统的状态分析
- PageRank 网页排名
- MCMC（马尔可夫链蒙特卡洛）参数估计

### 代码实现要点
```python
import numpy as np

def markov_steady_state(transition_matrix):
    """计算马尔可夫链的稳态分布"""
    P = np.array(transition_matrix, dtype=float)
    # 每行归一化
    P = P / P.sum(axis=1, keepdims=True)
    # 求解 πP = π（即 P^T π = π）
    eigenvalues, eigenvectors = np.linalg.eig(P.T)
    idx = np.argmin(np.abs(eigenvalues - 1.0))
    pi = np.real(eigenvectors[:, idx])
    pi = pi / pi.sum()
    return pi
```

### 选择指南
- 状态离散 + 无记忆性假设合适 → 马尔可夫链
- 需要随时间变化的参数 → 隐马尔可夫模型
- 需要从复杂分布采样 → MCMC

## 6. 微分方程建模

### 算法介绍
见 `model_library/differential.py`（ODE 数值解 + 一维热方程 PDE）。

### 适用范围
- 连续变化的动态系统
- 传染病模型（SIR/SEIR）
- 种群动力学（Lotka-Volterra）
- 热传导/扩散过程
- 力学与控制系统

### 选择指南
| 特征 | 方法 |
|------|------|
| 若干变量随时间连续变化 | ODE（scipy solve_ivp） |
| 空间+时间连续变化 | PDE（有限差分/有限元） |
| 带随机扰动的动态系统 | SDE（随机微分方程） |
| 离散事件/个体 | Agent-Based / 元胞自动机 |
