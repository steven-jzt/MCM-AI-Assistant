# 图论与网络分析算法说明

## 1. 最短路径问题

### 算法介绍
在加权图中寻找两点之间权重和最小的路径。

### 适用范围
| 条件 | 说明 |
|------|------|
| Dijkstra | 非负权图，单源最短路径 |
| Floyd-Warshall | 任意图（允许负权，无负环），全源最短路径 |
| Bellman-Ford | 允许负权边，单源最短路径 |
| A* | 有启发函数的大规模图，单源最短路径 |

### 典型应用
- 物流路径规划
- 通信网络路由
- 交通导航
- 设施选址

### 代码实现要点
```python
import networkx as nx
import numpy as np

def shortest_path_dijkstra(adj_matrix, source=0, target=None):
    """Dijkstra 最短路径（邻接矩阵输入）"""
    G = nx.from_numpy_array(np.array(adj_matrix))
    if target is not None:
        path = nx.dijkstra_path(G, source=source, target=target)
        length = nx.dijkstra_path_length(G, source=source, target=target)
        return path, length
    else:
        lengths = nx.single_source_dijkstra_path_length(G, source=source)
        return lengths
```

### 选择指南
- 单源非负权 → Dijkstra
- 全源 → Floyd-Warshall
- 有负权边 → Bellman-Ford
- 大规模+有启发信息 → A*

## 2. 最小生成树

### 算法介绍
在连通加权无向图中，找到一棵包含所有顶点且边权重和最小的树。

### 适用范围
- Prim 算法：稠密图
- Kruskal 算法：稀疏图

### 代码实现要点
```python
def minimum_spanning_tree(adj_matrix):
    """返回最小生成树的边集和总权重"""
    G = nx.from_numpy_array(np.array(adj_matrix))
    mst = nx.minimum_spanning_tree(G)
    edges = list(mst.edges(data=True))
    total_weight = sum(d['weight'] for _, _, d in edges)
    return edges, total_weight
```

在容量网络中，寻找从源点到汇点的最大流量分配方案。

### 典型算法
- Ford-Fulkerson（含 Edmonds-Karp BFS 实现）
- Dinic 算法（大规模网络）

### 代码实现要点
```python
def max_flow(capacity_matrix, source, sink):
    """最大流（邻接矩阵输入）"""
    G = nx.DiGraph()
    n = len(capacity_matrix)
    for i in range(n):
        for j in range(n):
            if capacity_matrix[i][j] > 0:
                G.add_edge(i, j, capacity=capacity_matrix[i][j])
    flow_value, flow_dict = nx.maximum_flow(G, source, sink)
    return flow_value, flow_dict
```

## 5. 欧拉路径与哈密顿路径

### 欧拉路径
经过图中每条边恰好一次的路径。充要条件（无向图）：恰有 0 或 2 个奇度顶点。

### 哈密顿路径
经过图中每个顶点恰好一次的路径。**NP 完全问题**，通常用回溯或启发式算法。

### 旅行商问题（TSP）
特殊的哈密顿回路问题：最小化总路程。竞赛中常用遗传算法、模拟退火、蚁群算法求解。

## 6. 匹配问题

### 算法介绍
在二分图（或一般图）中寻找最大匹配。

### 匈牙利算法
解决二分图最大匹配/最小代价完美匹配的经典算法。

```python
from scipy.optimize import linear_sum_assignment

def hungarian_assignment(cost_matrix):
    """匈牙利算法求解指派问题（最小化代价）"""
    row_ind, col_ind = linear_sum_assignment(np.array(cost_matrix))
    total_cost = np.array(cost_matrix)[row_ind, col_ind].sum()
    return list(zip(row_ind, col_ind)), total_cost
```

## 选择指南

| 问题特征 | 推荐算法 |
|---------|---------|
| 单源最短路径，非负权 | Dijkstra |
| 全源最短路径 | Floyd-Warshall |
| 大规模最短路径+启发 | A* |
| 连通成本最小化 | Prim（稠密）/ Kruskal（稀疏） |
| 流量分配最大化 | Dinic / Edmonds-Karp |
| 项目工期优化 | 关键路径法 |
| 任务指派 | 匈牙利算法 |
| 旅行商/TSP | 遗传算法 / 模拟退火 / 蚁群算法 |
