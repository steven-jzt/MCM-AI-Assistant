# 机器学习算法说明

## 1. 随机森林

### 算法介绍
Bagging 集成方法，通过多棵决策树的投票/平均来降低方差和提高泛化能力。每棵树在 bootstrap 样本上训练，每次分裂只考虑特征子集。

### 适用范围
- 分类和回归问题
- 特征重要性评估
- 数据量大（>500 行）、特征多的情况
- 对缺失值和异常值有较好的鲁棒性

### 关键参数
| 参数 | 建议 | 说明 |
|------|------|------|
| n_estimators | 100-500 | 树的数量，越大越稳定但计算越慢 |
| max_depth | 5-15 | 限制树深度防过拟合 |
| max_features | sqrt 或 log2 | 每次分裂考虑的特征比例 |
| min_samples_split | 5-20 | 节点再分裂的最小样本数 |
| random_state | 42 | 固定可复现 |

### 代码实现要点
```python
from sklearn.ensemble import RandomForestRegressor, RandomForestClassifier
from sklearn.model_selection import train_test_split, cross_val_score
import numpy as np

def random_forest_fit(X, y, task="regression", **kwargs):
    """随机森林拟合 + 交叉验证评估"""
    params = {"n_estimators": 200, "max_depth": 10,
              "random_state": 42, "n_jobs": -1}
    params.update(kwargs)

    if task == "classification":
        model = RandomForestClassifier(**params)
        scoring = "accuracy"
    else:
        model = RandomForestRegressor(**params)
        scoring = "neg_mean_squared_error"

    # 交叉验证
    cv_scores = cross_val_score(model, X, y, cv=5, scoring=scoring)
    model.fit(X, y)

    # 特征重要性
    importance = model.feature_importances_

    return model, cv_scores, importance
```

### 过拟合风险
- 中（当树太深或数据噪声大时）
- 缓解：限制 max_depth、增大 min_samples_split、增大 n_estimators

## 2. AdaBoost

### 算法介绍
自适应增强算法，通过迭代调整样本权重，让后续弱分类器关注被前一个分类器分错的样本。最终预测为加权多数投票。

### 适用范围
- 二分类/多分类问题
- 中小规模数据（对噪声敏感）
- 需要可解释的集成模型

### 代码实现要点
```python
from sklearn.ensemble import AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier

def adaboost_fit(X, y, n_estimators=100, learning_rate=0.5):
    """AdaBoost 拟合"""
    base = DecisionTreeClassifier(max_depth=1)
    model = AdaBoostClassifier(
        estimator=base, n_estimators=n_estimators,
        learning_rate=learning_rate, random_state=42
    )
    model.fit(X, y)
    return model
```

### 注意事项
- 对离群点和标签噪声敏感（权重会被异常样本主导）
- 学习率小 + 估计器多 → 通常更好但更慢

## 3. Isolation Forest

### 算法介绍
基于"异常点更容易被孤立"的直觉的非参数异常检测算法。通过随机特征和随机切分点构建隔离树，异常点的平均路径长度更短。

### 适用范围
- 异常检测/离群点识别
- 数据清洗（去除异常值）
- 欺诈检测
- 新颖性检测（novelty detection）

### 代码实现要点
```python
from sklearn.ensemble import IsolationForest

def detect_outliers(X, contamination=0.1):
    """Isolation Forest 异常检测
    contamination: 预期异常比例
    返回: -1=异常, 1=正常
    """
    model = IsolationForest(
        n_estimators=100, contamination=contamination,
        random_state=42, n_jobs=-1
    )
    labels = model.fit_predict(X)
    scores = model.decision_function(X)  # 越低越异常
    return labels, scores
```

## 机器学习在数学建模中的使用原则

### 适可而止
- 数据量 <100 行 → 不适合用机器学习（用传统统计方法）
- 数据量 100-500 行 → 谨慎使用，必须做交叉验证
- 数据量 >1000 行 → 可以考虑机器学习

### 可解释性要求
- 竞赛中评委更看重"为什么"而不是"多精确"
- 如果用了"黑箱"模型，必须额外做：
  - 特征重要性分析
  - SHAP 值或 LIME 局部解释
  - 与简单可解释模型的对比

### 过拟合风险
- 数据量小时机器学习极易过拟合
- 必须报告：训练集 vs 测试集误差对比
- 必须做：K 折交叉验证（至少 5 折）

### 与传统方法对比
- 如果随机森林的 R² 只比多元回归高 0.02，选回归（更可解释）
- 如果 LSTM 的 RMSE 比 ARIMA 还差，说明数据不够或未调优
- 模型评价章节必须包括至少一种传统模型作为基准

## 选择指南

| 场景 | 推荐算法 |
|------|---------|
| 表格数据分类/回归（>500 行） | 随机森林 |
| 需要特征重要性排序 | 随机森林 |
| 快速强分类器 | AdaBoost |
| 数据清洗/发现异常值 | Isolation Forest |
| 非线性关系建模 | 随机森林 > 核SVM |
| 评委需要可解释性 | 决策树 > 随机森林 > 神经网络 |
