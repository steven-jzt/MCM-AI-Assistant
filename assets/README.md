## 按问题类型速查

| 问题类型 | 推荐算法 |
|---------|---------|
| 综合评价/排名 | 熵权TOPSIS → AHP → 模糊综合评价 → DEA |
| 短序列预测（≤30 点） | GM(1,1) → 指数平滑 → 插值拟合 |
| 长序列预测（>100 点） | ARIMA → LSTM → XGBoost → Prophet |
| 线性/连续优化 | 线性规划 → 灵敏度分析 |
| 组合优化/NP-hard | 遗传算法 → 模拟退火 → PSO → 蚁群 |
| 多目标优化 | NSGA-II → 加权单目标 → 目标规划 |
| 分类/聚类 | K-means → 层次聚类 → 随机森林 |
| 机理建模 | 微分方程 → 元胞自动机 → 排队论 |
| 不确定性分析 | 蒙特卡洛 → 区间数评价 → 鲁棒优化 |

## 按数据类型速查

| 数据类型 | 推荐算法 |
|---------|---------|
| 结构化表格数据（>1000 行） | 随机森林、XGBoost、LSTM |
| 结构化表格数据（30-500 行） | 多元回归、ARIMA、PCA |
| 结构化表格数据（<30 行） | GM(1,1)、指数平滑 |
| 网络/图数据 | 最短路径、最小生成树、网络流 |
| 时空数据 | 差分方程、元胞自动机、时空预测 |
| 多源异构数据 | 先 PCA 降维/融合，再建模 |

## 使用方式

1. 确定问题类型 → 查 `assets/README.md` 速查表
2. 进入对应的 `0X-*.md` 查看具体算法说明（适用范围、关键文献、实现要点）
3. 优先调用 `model_library/` 中已有的 Python 实现
4. 若需新算法，参照 assets 中的实现要点编写代码
