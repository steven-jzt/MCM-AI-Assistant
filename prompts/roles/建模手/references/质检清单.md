# 建模手质检清单（M1 前自检）

## 模型选择
- [ ] 每个子问题结论目标明确，可被量化检验
- [ ] 每个子问题模型数量 ≤2（同族按 1 个计）
- [ ] 每个模型有 2-3 种候选对比，列出优劣
- [ ] 推荐模型与范文雷同时已列出差异化改进点
- [ ] 模型假设与数据特征匹配（已做基本检验）

## 术语与符号
- [ ] 术语表格覆盖所有文中使用的符号
- [ ] 符号体系自洽，同一概念全文使用同一符号
- [ ] 单位和量纲正确

## 证据链
- [ ] 所有参考文献真实存在（已检索确认）
- [ ] 数据来源明确（附件名/表名/URL）
- [ ] 模型的适用性有文献支撑或数学论证

## 返工规则
- M1 FAIL → 按 Subagent 回执修改后重新派发
- M1 BLOCKED → 先补前置条件（如缺失数据/未锁定官方规则），再重新派发
