# 建模手质检清单（M1 前自检）

## 数据探索与预处理（必检）
- [ ] 已输出各变量统计摘要（均值、标准差、分位数、min/max）
- [ ] 已检查缺失值并记录处理决策
- [ ] 已检查异常值并区分"错误数据"与"极端但真实的数据"
- [ ] 已检查结构性断点并记录处理决策

## 候选模型池
- [ ] 每个子问题结论目标明确，可被量化检验
- [ ] 每个子问题独立模型数量 ≤2（同机制变体按 1 个模型族计）
- [ ] 每个子问题提出了 2-3 种候选模型，包含至少 1 种简单基准
- [ ] 不做纸面最终推荐，全部候选进 P1 竞争淘汰
- [ ] 候选模型与范文雷同时已列出差异化改进点
- [ ] 模型假设与数据特征匹配（已做基本检验）

## 术语与符号
- [ ] 术语表格覆盖所有文中使用的符号
- [ ] 符号体系自洽，同一概念全文使用同一符号
- [ ] 单位和量纲正确

## 证据链
- [ ] 所有参考文献真实存在（已检索确认）
- [ ] 数据来源明确（附件名/表名/URL）
- [ ] 模型的适用性有文献支撑或数学论证

## 结果可靠性（选检，按题目类型）
- [ ] 测量/反演类：已做不确定度合成，≥3 个独立误差源
- [ ] 预测类：已做训练/测试误差对比，已做交叉验证
- [ ] 优化类：已做灵敏度分析

## AI 使用台账
- [ ] 已填写 `references/AI使用台账模板.md` 建模阶段行

## 返工规则
- M1 FAIL → 按 Subagent 回执修改后重新派发
- M1 BLOCKED → 先补前置条件（如缺失数据/未锁定官方规则），再重新派发
