# 建模手工作流程

## 完整流程

```
读题 → 定结论目标 → 选模型 → 检索证据 → 写交付物 → M1 → 反馈返工
```

## 步骤详解

### 1. 通读题目
- 提取问题背景、所有已知条件、数据说明、具体的提问点
- **保结构拆分**：保持原题的问题编号与层级，禁止打乱或合并
- 锁定官方规则 URL（mcm.edu.cn 或 COMAP），确认页数/格式/提交方式等硬约束
- 输出"问题结构映射表"

### 2. 提取数据/附件清单
- 列出所有附件文件，确认格式（CSV/Excel/MATLAB/JSON/TXT/PDF）
- 用 `utils/data_loader.py` 中的 `auto_load()` 尝试加载
- 记录：数据量（行列数）、缺失值情况、变量含义、单位

### 3. 形成结论目标清单
- 每个子问题最终要得出什么结论？
- 结论形式：数值 / 排名 / 分类 / 方案 / 预测区间 / 函数关系？
- 输出格式：表格 / 图表 / 数学表达式？

### 4. 选择模型
- 为每个子问题提出 2-3 种候选模型
- 对比：假设条件、数据要求、计算复杂度、可解释性
- **每个子问题 ≤2 个独立模型**（同机制变体 = 1 个模型族）
- 检查是否与范文雷同，若雷同须列出差异化改进点

### 5. 检索证据
- 参考文献：模型原始论文、教材、竞赛优秀论文
- 模型适用性：数据是否满足模型的数学假设？
- 数据支撑：样本量是否足够？是否存在多重共线性/异方差？

### 6. 撰写交付物

**题目分析报告.md** 应包含：
- 问题结构映射表
- 数据概览（来源、规模、质量）
- 各子问题结论目标
- 每个子问题的候选模型对比及最终推荐
- 模型假设与适用性论证
- 参考文献清单

**术语表格.md** 应包含：
| 符号 | 含义 | 单位 | 备注 |
|------|------|------|------|

### 7. M1 质量门
派发只读 Subagent，核验：
- 每个子问题结论可检验
- 模型数量符合规则
- 术语/符号自洽
- 数据来源可追溯
- 参考文献真实存在

### 8. 返工
- M1 驳回时，先改模型设计再补证据，而非先补证据再维持原模型
