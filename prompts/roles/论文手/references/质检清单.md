# 论文手质检清单（W1/W2 自检）

## W1 门自检 — 证据大纲

- [ ] Claim-Evidence 映射表完成，每个结论有对应证据
- [ ] 无"无源之水"式断言（数据/公式/图表/文献四类证据至少有一项支撑）
- [ ] 证据链闭环：数据→模型→结果→图表/表格→论文引用
- [ ] 所有图表/表格编号在正文中有引用

## W2 门自检 — 全文一致性

### 格式规范（对照 `references/论文规范摘要.md`）
- [ ] 页边距、字体、字号、行距符合要求
- [ ] 标题编号格式正确（一、/ （一）/ 1. / （1））
- [ ] 图表编号连续，引用正确
- [ ] 摘要 ≤1 页，正文 ≤30 页（CUMCM）

### 公式
- [ ] 无 LaTeX 编译错误
- [ ] 公式编号连续，无缺失/重复/未引用
- [ ] 公式符号与术语表格一致
- [ ] 所有符号首次出现时有定义

### 图表
- [ ] 每张图在正文中被引用至少一次
- [ ] 图题在图下方，表题在表上方
- [ ] 图表中数据与正文叙述一致
- [ ] 分辨率满足印刷要求（≥300 DPI）

### 参考文献
- [ ] 所有引用文献在正文中有标记
- [ ] 所有正文中的引用在参考文献列表中有条目
- [ ] 格式符合规范（期刊/书籍/网页格式区分）
- [ ] 无编造的文献

### 内容一致性
- [ ] 摘要中的关键数值与正文一致
- [ ] 结论与模型求解结果一致
- [ ] 符号全文统一（搜索确认无同义异符）
- [ ] 无各节之间复制粘贴导致的不一致

### 附录
- [ ] 包含完整可运行代码（或引用 `code/main.py`）
- [ ] 附录页数不计入正文 30 页限制

## 返工规则
- W1 FAIL/BLOCKED → 补证据链缺口，重新建立 Claim-Evidence 映射
- W2 FAIL → 按 Subagent 回执中的 P0/P1/P2 分级问题逐项修复
