# 论文手工作流程

## 完整流程

```
锁定规则 → 检查输入 → Claim-Evidence 映射 → W1 → 写正文 → 校验 → W2 → 交付
```

## 步骤详解

### 1. 锁定官方规则
- 查阅 `references/论文规范摘要.md`
- 确认：页边距、字体、字号、标题编号、图表公式编号格式
- 确认提交格式（PDF/DOCX）与命名规则
- 校赛规范与国赛规范冲突时，优先校赛规范

### 2. 检查输入
- P2 通过回执
- 全部结果文件（`results/`）
- 所有图表（`figures/` 中的 PNG）
- 复现清单（`results/复现清单.json`）
- 建模手的"题目分析报告.md"和"术语表格.md"

### 3. Claim-Evidence 映射
列出论文正文中每一句话（claim）对应的证据（evidence）：

| Claim | 证据类型 | 证据来源 |
|-------|---------|---------|
| "供应商A综合最优" | 图表 | 图3 result_q1_ranking.png |
| "预测误差RMSE<0.05" | 表格 | 表2 误差对比表 |
| "模型优于ARIMA基准" | 数值 | 表2 RMSE: 0.043 vs 0.087 |

### 4. W1 质量门
派发只读 Subagent 核验证据大纲：
- 每个结论都有可追溯证据
- 无"无源之水"式的断言
- 证据链闭环（数据→模型→结果→图表/表格→论文引用）

### 5. 撰写正文

按章节模板依次撰写（详见 `references/roles/论文手/references/章节模板.md`）：

1. **摘要**（最后写，≤1 页，3-5 个关键词）
2. **问题重述**（用自己的话概括，不照抄原文）
3. **问题分析**（结构映射表、各问间依赖关系）
4. **模型假设与符号说明**（引用"术语表格.md"）
5. **模型建立与求解**（核心章节，按子问题分节）
6. **结果分析**（物理意义解释、与基准对比）
7. **模型评价与推广**（优点、缺点、替代模型对比、改进方向）
8. **参考文献**
9. **附录**（完整代码清单，引用 `code/main.py`）

### 6. 格式校验
- 对照 `references/论文规范摘要.md` 逐项检查
- LaTeX 用户：首次编译前先运行 `xelatex` 或 `latexmk`
- 图表引用必须生效（`\ref{fig:xxx}` 编号正确）
- 参考文献引用完整

### 7. W2 质量门
派发只读 Subagent 核验：
- 公式符号与术语表格一致
- 图表编号与引用一致
- 文献引用存在且完整
- 每页图表编号格式正确
- 页数不超官方上限

### 8. 交付
- 论文 PDF 或 DOCX
- 确保文件名符合官方要求
- 附录包含完整可运行代码
