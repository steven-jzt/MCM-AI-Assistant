# 编程手工作流程

## 完整流程

```
读输入 → 环境检查 → P1 → 实现/运行 → 可视化 → 复现清单 → P2 → 返工
```

## 步骤详解

### 1. 读取输入
- `题目分析报告.md`：确认每个子问题的候选模型和求解目标
- `术语表格.md`：确认变量符号，代码中变量名与符号一致
- `data/` 中的附件数据

### 2. 环境检查
```bash
python check_env.py --features data,visualization,optimization,statistics
```
根据模型需要选择 feature。安装缺失依赖：
```bash
pip install -r requirements.txt
```

### 3. P1 质量门 — 候选模型竞争淘汰
在跑全量数据之前，在同一 mini-batch 数据集上运行建模手产出的所有候选模型（2-3 个）：
- 用前 N 行（如 N=100）数据验证每个候选的完整链路
- 产出 **竞争对比表**（核心指标 + 运行时间 + 数据假设满足度）
- 淘汰规则：复杂模型全指标不如简单基准则淘汰；指标接近（差距 < 10%）则全部保留；物理意义错误则立即淘汰
- 若所有候选均不满足要求 → 触发**二阶回退**，通知建模手重建候选池
- 派发只读 Subagent 核验

### 4. 实现模型
- 优先调用 `model_library/` 中的现有函数
- 代码组织在 `code/` 下，入口 `code/main.py`
- 设置 `random.seed(42)` 和 `np.random.seed(42)`（或 `np.random.default_rng(42)`）
- 关键参数在文件头部以常量/配置字典形式声明

### 5. 运行与校验
- 确认结果可一键复现（`python code/main.py`）
- 检查数值是否有明显异常（数量级错误、符号错误等）
- 与预期数量级/趋势对比

### 6. 可视化
- 每张图先写 figure contract（一句话结论 + 14 字段）
- 按 `references/roles/编程手/references/可视化规范.md` 执行
- 文件命名：`raw_q{题号}_{描述}` / `process_q{题号}_{描述}` / `result_q{题号}_{描述}`
- PNG + SVG 双格式保存至 `figures/`
- 运行 `figure_audit.py figures/`

### 7. 结果表格
- CSV 优先（UTF-8 BOM 编码，Excel 直接打开不乱码）
- 仅题目明确要求 XLSX 或需保留公式时才用 XLSX
- 表头清晰，数字保留 3-4 位有效数字

### 8. 复现清单
```bash
python references/roles/编程手/scripts/repro_manifest.py \
    --seed 42 --inputs data/ --command "python code/main.py"
```

### 9. P2 质量门
派发只读 Subagent，核验：
- 代码可运行性
- ≥9 张图（PNG + SVG 配对）
- figure_audit 通过
- 复现清单完整
- 结果表格与建模手结论一致
