# 审题与拆解

> 使用时机：拿到赛题后第一步。将赛题和数据文件放入对应目录后发送本提示。

---

请严格按照 CLAUDE.md 中的"审题与拆解（保结构拆分）"流程处理这道赛题。

## 输入
- 赛题文件：[`data/赛题.pdf` 或直接粘贴题目文字]
- 数据文件：[`data/xxx.xlsx`，列出所有附件文件名]

## 要求

### 1. 问题结构映射表
保持原题的问题编号与层级，按以下格式输出：

```
问题1：核心目标是...，涉及的数据有...，约束为...
  子问题1.1：...
  子问题1.2：...
问题2：基于问题1的结果，进一步要求...，新增条件...
  子问题2.1：...
问题3：综合考虑前两问，进行优化/预测/评价...
```

### 2. 依赖关系图
用文字或 ASCII 箭头说明各问题之间的输入输出关系，标注哪个问题的输出是另一个问题的输入。

### 3. 关键信息提取
- **已知条件**：列出题目中所有给定的参数、常数、边界条件
- **数据说明**：每个附件文件包含哪些字段、什么格式、数据量
- **约束条件**：分别列出硬约束（必须满足）和软约束（尽量满足）
- **评价指标**：题目要求以什么标准评价结果好坏

### 4. 潜在难点预警
对每问预判 1-2 个可能的难点或陷阱（如数据缺失、物理机理复杂、多目标冲突等）。

### 输出格式
以上四部分依次输出。确认拆解无误后，我会要求进入模型推荐环节。
