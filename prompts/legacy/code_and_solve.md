# 代码生成、运行与纠错

> 使用时机：模型推导完成，已有完整的数学公式和算法步骤。

---

请根据已建立的数学模型，编写可直接运行的 Python 代码。

## 要求

### 1. 代码结构
- 使用 `utils/data_loader.py` 读取数据文件
- 优先调用 `model_library/` 中的现成函数，必要时在此基础修改
- 代码存入 `code/` 文件夹，命名规则：`code/problem1_solve.py`、`code/problem2_solve.py`
- 提供一个 `code/main.py` 入口脚本，运行即复现全部结果

### 2. 代码规范
- 包含必要的库导入（numpy, pandas, scipy, matplotlib 等）
- 关键步骤加简短注释说明对应哪个公式/算法步骤
- 设置随机种子 `np.random.seed(42)` 确保结果可复现
- 输出结果保存到 `results/` 文件夹

### 3. 防过拟合检查
- 拟合模型必须输出训练/测试误差对比
- 给出过拟合风险评估（如：训练 R² 与测试 R² 差值 > 0.1 则预警）

### 4. 错误处理
- 对可能失败的操作（如矩阵奇异、优化不收敛）加 try-except 并给出备选方案
- 数值计算中避免除零、log(0) 等常见问题

### 5. 输出要求
- 运行 `python code/main.py` 应一键生成所有数值结果和图表
- 关键中间结果打印到控制台，详细结果保存为 CSV
- 图表使用 `utils/visual.py` 的函数，保存为 300 dpi PNG
