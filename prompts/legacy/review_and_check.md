# 终审检查清单

> 使用时机：提交前最后审查。

---

请对当前完成的论文、代码和附录进行全面审查，逐项检查以下清单。

## 一、格式合规检查

### 页面与排版
- [ ] A4 纸张，上下左右页边距 ≥ 2.5 cm
- [ ] 正文宋体小四号（或符合校赛规范）
- [ ] 一级标题黑体四号居中
- [ ] 行距 1.25 倍（或单倍行距）
- [ ] **无页眉**（硬性要求）
- [ ] 页码从摘要页开始，阿拉伯数字居中

### 结构完整性
- [ ] 摘要专用页（第1页，≤ 1 页）
- [ ] 正文（≤ 30 页）
- [ ] 参考文献（按引用次序排列）
- [ ] 附录（含完整可运行源代码）
- [ ] 无目录（竞赛论文不需要目录）

### 匿名要求
- [ ] 全文无参赛者姓名、学校、赛区信息
- [ ] 文件名不含身份信息

## 二、内容质量检查

### 摘要
- [ ] "问题→方法→结果"结构完整
- [ ] 关键词 3-5 个
- [ ] 无引用编号、图表编号
- [ ] 篇幅严格 ≤ 1 页

### 问题重述
- [ ] 用自己的话复述，不是照抄原题
- [ ] 各问题保持原编号和层级

### 问题分析
- [ ] 每问写出关键难点
- [ ] 末尾有总领段落（点明问题递进关系）
- [ ] 有整体思路流程图

### 模型假设
- [ ] 5-8 条假设
- [ ] **每条假设附合理性说明**（硬性要求）

### 数学推导
- [ ] 所有公式 LaTeX 格式
- [ ] 推导步骤完整，关键步骤未跳过
- [ ] 符号与符号说明表一致

### 结果呈现
- [ ] 关键结果在正文中展示
- [ ] 详细数据在附录中
- [ ] 每个结果有物理/实际意义的解释
- [ ] 图表编号连续，引用正确

### 模型评价
- [ ] 优点具体，有论据支撑
- [ ] 缺点诚实，不回避
- [ ] **包含与替代模型的对比**（硬性要求）
- [ ] 推广方向 2-3 个

### 参考文献
- [ ] 正文引用处标注编号
- [ ] 格式符合规范（书籍含页码）
- [ ] 包含期刊、标准、网页等多类型来源

## 三、代码与数据检查

### 代码
- [ ] 附录包含全部源代码，完整可运行
- [ ] 或明确声明"本论文没有用到程序"
- [ ] 代码运行结果与论文中的数值一致
- [ ] 拟合模型有训练/测试误差对比

### 数据
- [ ] 支撑材料文件列表在附录中
- [ ] 数据来源标注清晰

## 四、提交检查

### 电子版
- [ ] PDF 格式，≤ 20 MB
- [ ] 文件名：题号 + 参赛队编号 + 队员 + 论文题目
- [ ] 支撑材料压缩为 RAR/ZIP，≤ 20 MB
- [ ] 支撑材料不含承诺书和身份信息

### AI 使用声明（如适用）
- [ ] 附录中包含 AI 工具使用说明（工具名称、使用问题、采用信息）

---

请逐项检查并报告：
1. 通过项（无需修改）
2. 问题项（描述具体问题 + 建议修改方案）
3. 缺失项（需补充的内容）
