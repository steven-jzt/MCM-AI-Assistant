# 模型推荐与对比

> 使用时机：问题拆解完成，已输出问题结构映射表。

---

基于上一步的问题拆解结果，请为每个子问题推荐模型。

## 要求

### 对每个子问题，按以下格式输出：

```
[子问题编号] [子问题核心目标]

候选模型1：[模型名称]
  - 原理简介：一句话说明
  - 优点：
  - 缺点：
  - 适用条件：

候选模型2：[模型名称]
  - （同上）

候选模型3：[模型名称]（如有）
  - （同上）

最终推荐：[模型名称]
  推荐理由：
  - 与本题数据特征的匹配度
  - 与已有条件的兼容性
  - 实现难度与可解释性
```

### 模型串联逻辑
用 ASCII 流程图展示所有子问题的模型如何串联：

```
问题1: [模型A] → [输出1]
                  ↓
问题2: [模型B(输入=输出1)] → [输出2]
                  ↓
问题3: [模型C(输入=输出2)] → 最终结果
```

### 防过拟合检查
对照 CLAUDE.md 的防思维过拟合规则，逐条说明：
1. 本题与范文场景的差异是什么？
2. 如推荐模型与范文雷同，提出至少 1 条差异化改进点。
3. 确认问题结构与范文模型串联顺序是否匹配。

### 备选方案
为每个子问题保留 1 个备选模型，说明在什么情况下应切换到备选方案（如主模型假设不成立、数据不支持等）。

---

请确认推荐方案后，我将要求进入模型推导环节。
